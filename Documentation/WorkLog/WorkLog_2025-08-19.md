### 2. Table脚本重构 
**文件**: `Assets/PongHub/Scripts/Gameplay/Table/Table.cs`

**重构目标**: 移除Table脚本对BoxCollider组件的强依赖，改为与TablePart系统协作

**主要修改**:

#### 2.1 移除组件依赖
- **删除**: `[RequireComponent(typeof(BoxCollider))]` 属性
- **删除**: BoxCollider相关字段 (`m_tableCollider`, `m_netCollider`, `m_edgeCollider`)
- **删除**: 碰撞边界字段 (`m_tableBounds`, `m_netBounds`, `m_edgeBounds`)

#### 2.2 新增TablePartManager集成
- **新增**: `m_tablePartManager` 字段，用于与TablePart系统协作
- **修改**: 类注释，明确说明"碰撞检测由TablePart系统管理"

#### 2.3 重构初始化方法
**`InitializeComponents()`方法变更**:
```csharp
// 移除前
if (m_tableCollider == null)
    m_tableCollider = GetComponent<BoxCollider>();

// 修改后  
m_tablePartManager = GetComponent<TablePartManager>();
```

#### 2.4 重构碰撞体设置
**`SetupColliders()`方法完全重写**:
```csharp
// 修改前: 直接操作BoxCollider组件
m_tableCollider.size = new Vector3(...);
m_tableCollider.material = new PhysicMaterial(...);

// 修改后: 委托给TablePartManager
if (m_tablePartManager != null)
{
    m_tablePartManager.ConfigureFromTableData(m_tableData);
}
```

#### 2.5 移除碰撞处理
- **删除**: `OnCollisionEnter(Collision collision)` 方法
- **删除**: `CalculateHitForce(Vector3 ballVelocity)` 方法
- **原因**: 碰撞检测现在由各个TablePart组件独立处理

### 3. TablePartManager功能扩展
**文件**: `Assets/PongHub/Scripts/Gameplay/Table/TablePartManager.cs`

**新增方法**: `ConfigureFromTableData(TableData tableData)`

**功能描述**:
- 根据TableData自动配置所有TablePart组件的碰撞体尺寸和物理材质
- 支持桌面(Surface)和球网(Net)部件的自动配置
- 包含详细的调试日志输出

**实现细节**:
```csharp
// 桌面部件配置
if (m_partsByType.ContainsKey(TablePartType.Surface))
{
    foreach (var surfacePart in m_partsByType[TablePartType.Surface])
    {
        if (surfacePart?.Collider is BoxCollider boxCollider)
        {
            boxCollider.size = new Vector3(tableData.Width, 0.1f, tableData.Length);
            boxCollider.center = tableData.GetTableCenter();
            // 设置物理材质...
        }
    }
}
```

## 架构优化成果

### 解决的问题
1. **Unity编辑器错误**: 解决了"Can't remove BoxCollider because Table (Script) depends on it"错误
2. **组件耦合**: Table脚本不再直接依赖BoxCollider组件
3. **职责分离**: Table专注空间锚点功能，碰撞检测由TablePart处理

### 架构改进
1. **模块化设计**: TablePart系统完全独立管理碰撞检测
2. **配置统一**: TablePartManager统一配置所有子组件
3. **维护性提升**: 修改碰撞逻辑只需修改TablePart，不影响Table

### 现在的组件职责划分
- **Table**: VR空间锚点、坐标转换、视觉效果管理
- **TablePartManager**: 统一管理所有TablePart组件配置
- **TablePart**: 独立的碰撞检测、音效播放、物理属性管理
